# 打卡

上班

下班

同一天内第一次打卡记录上班的情况

第二次打卡记录下班的情况

第三次打卡失效

数据库无用户当天打卡记录，则是上班打卡，存入数据库，上班时间，下班时间为空

数据库有用户当天打卡记录，并且下班时间为空，则是下班打卡，更新数据库，存入下班时间

数据库有用户当天打卡记录，并且下班时间不为空，说明当天已完成上下班考勤，提示打卡无效

同时有迟到、早退、请假等特殊打卡状态进行标注
