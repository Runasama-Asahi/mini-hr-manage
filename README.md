# HR 管理系统


#### 介绍
{**以下是 人事管理系统 说明**}

#### 软件架构
软件架构说明
单体架构，非前后端分离
基于 Spring Boot 3.2.5 + MyBatis Plus + Spring Security + LangChain4j 的 HR 管理系统，支持 AI 智能助手功能。

## 技术栈

| 组件 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3.2.5 |
| Java 版本 | 17 |
| ORM | MyBatis Plus 3.5.7 |
| 安全框架 | Spring Security 6 + JWT |
| AI 框架 | LangChain4j 1.12.2 + LangGraph4j 1.8.13 |
| 数据库 | MySQL 8.0 |
| 前端 | Thymeleaf + LayUI + jQuery |
| API 文档 | SpringDoc OpenAPI 3.0 (Swagger) |

#### 使用说明

登录入口写好，后续的逻辑验证限交给Shiro

LayUI 前端框架 数据是异步加载

特定的数据格式 DataGridView

先加载前端页面，再通过 Ajax 请求后端数据接口，前端再进行加载

## 3. 项目目标

### 3.1 总体目标
开发一套功能完善、操作便捷的企业人力资源管理系统，实现企业人力资源管理的数字化、信息化和规范化。

### 3.2 具体目标
- 实现员工信息管理功能，包括员工档案、部门管理、角色权限管理
- 实现考勤管理功能，包括上下班打卡、考勤记录查询、迟到早退统计
- 实现绩效管理功能，包括绩效考核、绩效奖金计算
- 实现薪酬管理功能，包括工资计算、工资发放、工资查询
- 实现培训管理功能，包括培训计划制定、培训记录管理
- 实现审批管理功能，包括请假审批、转正审批等
- 实现系统权限管理，确保数据安全和操作权限控制

## 5. 项目涉及技术与重难点分析

### 5.1 项目涉及技术

#### 5.1.1 后端技术
- **Spring Boot**：简化Spring应用开发的框架，提供自动配置和快速开发能力
- **MyBatis-Plus**：MyBatis的增强工具，简化CRUD操作，提高开发效率
- **Apache Shiro**：强大的Java安全框架，提供认证、授权、加密和会话管理
- **Thymeleaf**：现代服务器端Java模板引擎，用于Web和独立环境

#### 5.1.2 前端技术
- **Layui**：模块化前端UI框架，提供丰富的UI组件
- **Thymeleaf**：用于服务器端渲染的模板引擎
- **jQuery**：快速、简洁的JavaScript库，简化HTML文档操作

#### 5.1.3 数据库技术
- **MySQL**：关系型数据库管理系统，用于存储系统数据
- **MyBatis-Plus Generator**：代码生成器，快速生成Entity、Mapper、Service等代码

### 5.2 项目重难点分析

#### 5.2.1 权限管理
**难点**：
- 实现基于RBAC（角色-权限）的访问控制
- 实现细粒度的权限控制，包括菜单权限和操作权限
- 处理用户、角色、权限之间的多对多关系

**解决方案**：
- 使用Apache Shiro实现认证与授权
- 设计用户-角色-权限的数据模型
- 自定义Realm实现用户认证与授权逻辑
- 使用Shiro注解控制方法级别的访问权限

#### 5.2.2 考勤管理
**难点**：
- 实现上下班打卡功能，判断迟到、早退、加班等状态
- 处理打卡记录与工资计算的关联
- 处理打卡数据的准确性和完整性

**解决方案**：
- 设计考勤记录表，记录打卡时间和状态
- 使用配置文件定义上班、下班和加班时间
- 实现打卡状态判断逻辑，包括迟到、早退、加班等状态
- 考勤记录与工资记录关联，实现考勤扣款计算

#### 5.2.3 薪酬计算
**难点**：
- 实现复杂的薪酬计算逻辑，包括基本工资、绩效奖金、各种扣款等
- 处理绩效考核与薪酬的关联
- 确保薪酬计算的准确性和一致性

**解决方案**：
- 设计薪酬记录表，记录工资各组成部分
- 实现薪酬计算逻辑，包括基本工资、绩效奖金、各种扣款
- 绩效考核与薪酬关联，根据绩效考核结果自动计算绩效奖金
- 实现薪酬记录的增删改查功能

#### 5.2.4 审批流程
**难点**：
- 实现灵活的审批流程
- 处理审批状态流转
- 确保审批流程的完整性和可追溯性

**解决方案**：
- 设计审批申请表，记录申请内容、审批人、审批意见等信息
- 实现审批状态流转逻辑，包括待审批、已审批、已拒绝等状态
- 实现审批记录查询功能，确保审批流程可追溯
- 防止自审批，确保审批流程的合理性

#### 5.2.5 系统集成
**难点**：
- 整合各个功能模块，确保系统整体运行稳定
- 处理模块间的数据交互和业务逻辑关联
- 确保系统性能和用户体验

**解决方案**：
- 采用分层架构设计，降低模块间耦合度
- 使用统一的异常处理和日志记录机制
- 实现统一的响应格式，便于前端处理
- 进行充分的集成测试，确保系统稳定运行

### 5.3 项目特色
1. **权限管理**：基于RBAC的权限控制，实现细粒度的权限管理
2. **考勤管理**：智能判断考勤状态，包括迟到、早退、加班等
3. **薪酬计算**：自动计算工资，包括基本工资、绩效奖金和各种扣款
4. **审批流程**：灵活的审批流程，支持多种业务场景
5. **系统安全**：使用Shiro实现安全认证和授权，确保系统安全

1. **性能优化**：优化数据库查询，提高系统响应速度
2. **用户体验**：优化前端界面，提升用户体验
3. **功能扩展**：根据实际需求，扩展更多功能模块
